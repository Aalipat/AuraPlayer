## ✨ قابلیت‌های برجسته

### 🎧 ۱. پخش و دانلود تخصصی اسپاتیفای (Spotify)
- **کیفیت استثنایی:** دریافت موزیک‌ها با کیفیت صوتی ۳۲۰kbps با بالاترین وفاداری صوتی.
- **پشتیبانی جامع:** استخراج خودکار تمامی لینک‌های **Track**، **Album** و **Playlist**.
- **تزریق برچسب‌های متاداده (ID3 Tagging):** الصاق نام خواننده، آلبوم، سال انتشار، عنوان ترانه و کاور رسمی با بالاترین وضوح درون فایل صوتی.
- **بدون نیاز به حساب پریمیوم:** دانلود بدون نیاز به اکانت پریمیوم و رهایی از قفل‌های DRM.

### 📺 ۲. دانلود پیشرفته یوتیوب و زیرنویس پادکست‌ها (YouTube)
- **کیفیت‌های متنوع:** دریافت ویدیو تا رزولوشن‌های **4K**، **1080p**، **720p**، **480p** و نسخه مجزای صوتی (MP3/Opus).
- **پادکست و زیرنویس دوزبانه:** استخراج زیرنویس ویدیوها و ترجمه هوشمند دوطرفه (انگلیسی به فارسی و فارسی به انگلیسی) همگام با زمان ویدیو.

### 🎤 ۳. لیریکس زنده به سبک کارائوکه و ترجمه فارسی (Live Synced Lyrics)
- **اسکرول خودکار هوشمند:** حرکت خط‌به‌خط لیریکس متناسب با ثانیه‌شمار آهنگ با هایلایت زمردی.
- **انتخابگر سه‌حالته:** جابجایی بین **متن اصلی انگلیسی**، **ترجمه روان فارسی** یا **حالت دوزبانه (Bilingual)** با ۱ کلیک.
- **خروجی استاندارد:** تولید خودکار فایل‌های `.lrc` و `.txt` برای استفاده در پلیرهای موبایل و ویندوز.

### 🪟 ۴. مینی‌پلیر شناور لوکس (Floating Luxury MiniPlayer)
- **پنجره دسکتاپ مستقل:** امکان انتقال پلیر به پنجره شناور کوچک و مدرن با گوشه‌های خمیده.
- **قابلیت همیشه در دید (Always-on-Top):** پین کردن روی تمام برنامه‌ها هنگام کار یا وب‌گردی.
- **تایم‌لاین تعاملی (Seekable Scrubber):** پرش مستقیم به هر ثانیه از آهنگ با کلیک روی نوار پیشرفت.
- **هاله نورپردازی تطبیقی:** تغییر ملایم تم رنگی متناسب با رنگ‌های کاور آهنگ در حال پخش.

### ⏰ ۵. صف دانلود هوشمند و زمان‌بندی شبانه (Smart Queue & Night Scheduler)
- افزودن چندین لینک به صف و تعیین اولویت برای دانلود ترتیبی خودکار.
- امکان زمان‌بندی دانلود در ساعات شبانه برای صرفه‌جویی در مصرف اینترنت.

### 🛡️ ۶. تشخیص خودکار و سازگاری با پروکسی و تحریم‌ها
- بررسی و اتصال هوشمند به درگاه‌های فعال پروکسی لوکال (V2Ray, Clash, sing-box) و فیلترشکن‌های سیستمی (WireGuard, WARP, Outline).
- امکان تعیین دستی آدرس و پورت پروکسی در صورت تمایل.

## 🛠️ معماری فنی و استک نرم‌افزار

- **Desktop Shell:** C# Windows Forms (.NET 10) + Microsoft Edge WebView2
- **Backend Core:** Python 3.12 Embedded Runtime + FastAPI + Uvicorn
- **Engines:** `yt-dlp` + `ffmpeg` + `ffprobe`
- **Frontend:** HTML5, Modern Tailwind CSS (Glassmorphism & Ambient Glow), FontAwesome 6, Vazirmatn Font
- **Lyrics Database:** LRCLIB API & Synced Subtitles Parser
