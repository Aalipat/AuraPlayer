# 🎵 YouTube & Spotify Advanced Downloader Panel
> پنل مدرن و محلی دسکتاپ برای دانلود ویدیو و موزیک از یوتیوب و اسپاتیفای به همراه لیریکس همگام‌سازی‌شده فارسی

این پروژه یک نرم‌افزار دسکتاپ مستقل و سبک بر پایه **FastAPI**، **yt-dlp**، موتور جستجوی هوشمند **اسپاتیفای** و رابط کاربری مدرن فارسی (**Tailwind CSS RTL**) است.

---

## ✨ ویژگی‌های برجسته

1. **دانلود کامل از یوتیوب (YouTube Downloader):**
   - دریافت ویدیو تا کیفیت‌های 4K / 1080p / 720p و فایل صوتی مجزا (MP3 / M4A).
   - دریافت خودکار زیرنویس و ترجمه به زبان فارسی.
   - نمایش لحظه‌ای درصد پیشرفت، حجم، سرعت دانلود و زمان باقی‌مانده.

2. **دانلود تخصصی از اسپاتیفای (Spotify Downloader):**
   - پشتیبانی از تمام لینک‌های **Track**، **Album** و **Playlist**.
   - تطبیق هوشمند با آرشیو رسمی موزیک بدون نیاز به حساب کاربری پریمیوم اسپاتیفای و بدون قفل DRM.
   - تزریق تگ‌های رسمی ID3 (نام خواننده، آلبوم، سال انتشار، عنوان) همراه با **کاور باکیفیت و اورجینال اسپاتیفای** داخل فایل MP3.

3. **متن ترانه و ترجمه هوشمند فارسی (Synced Persian Lyrics):**
   - دریافت متن ترانه با تایم‌کد دقیق میلی‌ثانیه‌ای (`.lrc` و `.txt`) از پایگاه‌های داده LRCLIB و Musixmatch.
   - ترجمه خودکار خط‌به‌خط اشعار به فارسی روان با حفظ زمان‌بندی دقیق.
   - امکان ذخیره فایل `.lrc` در کنار موزیک برای نمایش لیریکس متحرک در پلیرهای موبایل و ویندوز.

4. **سیستم مدیریت دانلود همزمان (Concurrent Queue):**
   - امکان ثبت همزمان چندین دانلود و پردازش موازی در پس‌زمینه.
   - حفظ و بازیابی کامل وضعیت دانلودها حتی در صورت بستن یا ریفرش کردن مرورگر.

5. **پشتیبانی کامل از فیلترشکن‌ها و پروکسی‌ها:**
   - تشخیص خودکار پورت‌های فعال پروکسی لوکال (مانند V2Ray, Xray, Clash, sing-box) و سازگاری بی‌نقص با فیلترشکن‌های سیستمی (WireGuard, WARP, OpenVPN).
   - قابلیت تنظیم پورت دستی یا تغییر به حالت اتصال مستقیم (Direct).

6. **مدیریت مسیر ذخیره‌سازی:**
   - پنجره انتخاب پوشه پیشرفته ویندوز (Windows Folder Picker) برای تعیین پوشه دلخواه جهت ذخیره دانلودها.
   - دکمه باز کردن پوشه و هایلایت خودکار فایل دانلود شده در Windows Explorer.

## 🚀 راهنمای سریع راه‌اندازی و اجرا

### پیش‌نیازها:
- ویندوز ۱۰ یا ۱۱ (یا لینوکس / مک)
- پایتون نسخه ۳.۱۰ یا بالاتر ([دانلود از python.org](https://www.python.org/downloads/)) - *دقت کنید در هنگام نصب تیک `Add python.exe to PATH` را بزنید.*
- برنامه **FFmpeg** برای ادغام صدا و تصویر با بالاترین کیفیت در یوتیوب (اختیاری اما توصیه شده).

### مراحل اجرا:
1. فایل زیپ را در مسیر دلخواه خود استخراج (Extract) کنید.
2. فقط کافیست روی فایل **`YouTube_Downloader.exe`** دوبار کلیک کنید.
3. برنامه به صورت کاملاً خودکار و مستقل، هسته دانلود و پنل مدرن را لود کرده و در یک پنجره دسکتاپ لوکس بدون نیاز به باز بودن هیچ فایل یا پنجره کنسولی اجرا می‌شود.
4. سرور محلی نیز در آدرس زیر در دسترس است:
   ```
   http://127.0.0.1:8000
   ```

## ⚙️ تنظیمات (فایل `.env`)

در فایل `.env` می‌توانید تنظیمات را شخصی‌سازی کنید:
- `PROXY_URL=auto` : حالت تشخیص خودکار پروکسی (یا `direct` برای اتصال مستقیم بدون پروکسی، یا مثلاً `http://127.0.0.1:10808`).
- `DOWNLOAD_DIR=data/downloads` : مسیر پیش‌فرض ذخیره‌سازی فایل‌ها.
- `BOT_TOKEN=` : در صورتی که تمایل داشته باشید از ربات تلگرام این سورس نیز استفاده کنید، می‌توانید توکن ربات تلگرام خود را از BotFather دریافت و در این قسمت قرار دهید (برای پنل دسکتاپ اختیاری است).

## 📁 ساختار پروژه

```
├── data/
│   ├── downloads/            # پوشه پیش‌فرض ذخیره فایل‌های صوتی و تصویری
│   └── transcripts/          # پوشه ذخیره متن ترانه‌ها و زیرنویس‌ها
├── src/
│   ├── panel/                # اپلیکیشن وب پنل FastAPI و رابط کاربری فارسی
│   ├── services/             # سرویس‌های دانلود یوتیوب، اسپاتیفای و ترجمه زیرنویس
│   ├── bot/                  # کدهای مربوط به ربات تلگرام (اختیاری)
│   └── utils/                # ابزارهای کمکی تشخیص پروکسی و فرمت‌بندی
├── tests/                    # تست‌های یکپارچه و خودکار سیستم
├── requirements.txt          # کتابخانه‌های پایتون مورد نیاز
├── launcher.py               # لانچر هوشمند و ساخت خودکار venv و نصب پکیج‌ها
├── YouTube_Downloader.exe    # لانچر رسمی و مستقل دسکتاپ (فقط با یک دابل‌کلیک)
├── app_icon.ico              # آیکون رسمی برنامه
└── README.md                 # راهنمای برنامه
```
